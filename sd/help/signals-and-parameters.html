Project Panel - View and Edit Signals and Parameters

After the project data is loaded, all signals and parameters are listed in the “Signals” and “Parameters” sub-panels. You can click on a signal or parameter name to view more details. To filter the list, simply type part of the signal or parameter name in the search box. In the “Signals” sub-panel, you can also click the signal location text to open the model file with the corresponding signal selected and highlighted.
