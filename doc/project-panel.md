# Project Panel

The Project Panel lets you scan and load Simulink models, inspect signals and parameters, and run simulations in Normal Mode or Unit Mode.

Documentation for this section is not yet complete, and no examples are currently provided. For more information, please contact the author at jianfei.yu@kinzed.com.

## Sections

- **[Scan and Load a Model](scan-and-load.md)** — scan, load, or re-scan a Simulink project.
- **[View and Edit Signals and Parameters](signals-and-parameters.md)** — browse, filter, and navigate signals and parameters.
- **[Simulation in Normal Mode](normal-mode.md)** — run a full MiL simulation and view signal values.
- **[Simulation in Unit Mode](unit-mode.md)** — run fast unit simulations using pre-configured unit models.

## Future Development Plan

The project panel is still under development. I am trying to make the unit model mechanism to be further simpler and more user-friendly.

- To-Workspace and From-Workspace blocks will not be required.
- Tools to automatically create unit models will be provided.
- Integration with the Simulink Test framework will be added.
- Exporting simulation data to MDF files.
- Easier signal and parameter management.
- ...

Current unit model mechanism can already boost efficiency significantly, you can contact me to help you set it up for your project.
