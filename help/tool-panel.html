Tool Panel

The Tool Panel provides a comprehensive set of utilities to boost Simulink modeling efficiency. Its buttons are organized into functional groups covering block layout, signal routing, bus creation, and more.

Common features

  • Hover over a button — a short function description appears at the top of the panel.
  • Right-click a button — a context menu pops up with additional options and help links.
  • Undoable actions - when the mouse hovers over a button, if the boundary color changes to blue, it indicates that the action performed by that button can be undone using Ctrl+Z.

Sections

  • General Block Manipulations — align, show/hide names, adjust height, and add/remove I/O ports on selected blocks.
  • Signal Routing Blocks — generate and manage Inport/Outport and Goto/From blocks.
  • Line Manipulations — set signal names, propagation, and stream properties on lines.
  • Information & Block Format — track signals, copy values, and apply pre-defined block styles.
  • Signal Renaming — propagate and synchronise signal names across the model.
  • Bus & Data Dictionaries — additional utilities including bus object creation.
