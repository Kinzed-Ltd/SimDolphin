Project Panel - Simulation in Normal Mode

Click this button to run a full simulation.

After running a simulation, you can view the value of any signal in the project panel. In the signal listbox, double-clicking a signal name will add it to the “Signals to check” listbox. Clicking “View simulation data” will display all values of the signals in the “Signals to check” listbox in a Simulation Data Inspector window. If the selected signals are already logged, values will be shown immediately. Otherwise, a full MiL simulation will be run automatically, and the values will be displayed in the Simulation Data Inspector window after the simulation finishes.
